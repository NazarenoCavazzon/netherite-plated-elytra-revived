## Descripción (EN) — pegar tal cual

```markdown
# Netherite Plated Elytra

An **upgraded elytra** for **Minecraft 26.1.2 / 26.2 (Fabric)**. Take your hard-earned elytra to the next tier the same way you upgrade any tool or armor: at the **smithing table**, with a netherite upgrade template and a netherite ingot.

## ✨ Features

- 🔥 **Fireproof** — it will not burn in fire or lava.
- 🛡️ **+4 Armor** while worn in the chest slot.
- ❤️ **864 durability** — exactly **2×** the vanilla elytra (432).
- 🪶 **Glides like the vanilla elytra** — same flight, just better.
- 🎨 **Netherite look** — dark wings with subtle gold details (plus a damaged variant).

## 🔨 Crafting

Place these on a **Smithing Table**:

| Slot | Ingredient |
|---|---|
| Template | Netherite Upgrade Smithing Template |
| Base | Elytra |
| Addition | Netherite Ingot |
| → Result | **Netherite Plated Elytra** |

## 📦 Requirements

- **Fabric Loader** 0.19.5+
- **Fabric API** — **required** (Fabric API is what allows new items to be registered on 26.x)
- **Minecraft 26.2** or **26.1.2** — pick the file that matches your game version

## 🔧 Compatibility

- Works alongside **Do a Barrel Roll**, **Elytra HUD+** and any other elytra mod.
- Must be installed on **both client and server** (same version).
- Multiplayer-friendly: no mixins, no config, no performance impact.

## 📝 Notes

- **Repairable** with netherite ingots in an anvil.
- This is an **unofficial, community-made** mod for the modern versions; it is **not affiliated** with the original "Netherite Plated Elytra" project.
- Item textures are a recolor of Mojang's vanilla elytra texture.

## 💬 Found a bug or have a suggestion?

Open an issue on the source repository. Enjoy your flights!
```
